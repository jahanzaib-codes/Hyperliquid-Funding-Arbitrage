# 🤝 Contributing to Hyperliquid-Funding-Arbitrage

Thank you for contributing to **Hyperliquid-Funding-Arbitrage**! We welcome contributions from quant developers, DeFi traders, and arbitrage researchers.

## 📋 Code of Conduct
We maintain a professional, collaborative, and inclusive environment.

## 🛠️ Development Setup
1. **Fork and Clone:**
   ```bash
   git clone https://github.com/<your-username>/Hyperliquid-Funding-Arbitrage.git
   cd Hyperliquid-Funding-Arbitrage
   ```
2. **Environment Setup:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

## 🚀 Pull Request Process
1. Verify syntax and static analysis passes (`flake8 . --count --select=E9,F63,F7,F82`).
2. Update documentation and changelogs.
3. Submit PR against `main`.
