# 🔒 Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We prioritize API key security, wallet signature safety, and margin risk controls:

1. **Do not disclose publicly:** Please avoid creating public GitHub issues for security reports.
2. **Contact Channel:** Reach out directly via Telegram at [@JanzebBlockdev](https://t.me/JanzebBlockdev) or verified portfolio links.
3. **Response Timeline:** Acknowledged within 48 hours.
